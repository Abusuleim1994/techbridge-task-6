Your 30-day internship journey

TechBridge provides a structured 30-day practical internship made up of 8 tasks. You progressively develop your web development skills by completing practical projects, starting with the homepage and ending with a complete platform.

The 8 tasks

Select "What you will build" on any task to see more.

  1. Day1

    Task 1

    Build the TechBridge Homepage

    Beginner

    Create the first version of the TechBridge website using HTML and CSS.

    What you will build

    Goal: the first version of the TechBridge website.

    Tools: HTML5 and CSS3.

    Where it fits: the starting point of the internship.

  2. Day4

    Task 2

    Build the TechBridge Programs Experience

    Beginner → Intermediate

    Create a Programs experience that presents TechBridge's available learning programs.

    What you will build

    Goal: a Programs page presenting Data Analytics and Web Development.

    Tools: HTML5 and CSS3.

    Where it fits: builds on your Task 1 homepage.

  3. Day8

    Task 3

    Build the Internship Tasks Experience

    Beginner → Intermediate

    Create an interface that presents the TechBridge internship tasks and helps users understand the internship journey.

    What you will build

    Goal: a page showing all 8 tasks and how the internship progresses.

    Tools: HTML5 and CSS3.

    Where it fits: builds on Tasks 1 and 2, and connects Home, Programs and Internship Tasks.

  4. Day11

    Task 4

    Build an Interactive Task Tracker

    Intermediate

    Use JavaScript to make the internship task experience interactive and allow progress to be tracked.

    What you will build

    Goal: an interactive version of the task experience where progress can be tracked.

    Tools: JavaScript.

    Where it fits: builds on the Task 3 page.

  5. Day15

    Task 5

    Build the Intern Registration Experience

    Intermediate

    Create a professional registration/onboarding interface for TechBridge interns.

    What you will build

    Goal: a professional registration and onboarding interface for interns.

    Where it fits: introduces registration and onboarding to the platform.

  6. Day19

    Task 6

    Build the Task Submission System

    Intermediate

    Create an interface through which interns can prepare and submit their task work.

    What you will build

    Goal: an interface where interns prepare and submit their task work.

    Where it fits: lets interns hand in what they build in each task.

  7. Day22

    Task 7

    Build the Intern Dashboard

    Intermediate → Advanced

    Create a dashboard where an intern can view their profile, progress, tasks, and submissions.

    What you will build

    Goal: a dashboard showing an intern's profile, progress, tasks and submissions.

    Where it fits: brings an intern's information into one view.

  8. Day26

    Task 8

    Build the Complete TechBridge Internship Platform

    Intermediate → Advanced

    Combine the different components created during the internship into a complete TechBridge platform.

    What you will build

    Goal: one complete TechBridge platform made from the components you built.

    Where it fits: the final task, where everything comes together.
